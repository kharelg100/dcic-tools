# DCIC Evidence Tools

Interactive companion to the research briefs prepared for the City of Fort Worth Data Center and Infrastructure Commission (DCIC), October 2026.

| Tool | File | Companion to |
|---|---|---|
| Pillar 3 Equity Tool | `equity-tool.html` | Section 4.3.5, Equity and cumulative burden |

The tool is a single self-contained HTML file: open it in any web browser, from this site or from a downloaded copy. No installation, no server, no data collection. The `versions/` folder holds dated copies of each release; the top-level file is always the current version.

Prepared by Dr. Gehendra Kharel, STREAM Lab, Texas Christian University. The tool describes evidence; it does not recommend for or against data centers and is not a legal opinion.

Data sources are stated inside the tool. Site and campus records are as of September 19, 2026 (City of Fort Worth GIS, CDC/ATSDR Environmental Justice Index 2024, TEA 2023 to 2024 campus points, HHSC licensed child-care records).
